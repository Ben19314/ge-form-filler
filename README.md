# Nomination Form Filler

Fills the Great Eastern **Appointment / Change of Nominee(s) / Trustee(s)** form (NBZ-FNOMI-V07-082025) from customer details typed in, pasted from WhatsApp, read from IC photos, or uploaded from Excel.

- **Open the app:** `Nomination Form Filler.html` (or the GitHub Pages link for this repo).
- **Guide:** [HOW TO USE.md](HOW%20TO%20USE.md)

Everything runs in the browser. Customer details are saved only in the browser that uses the app (localStorage), never in this repository and never sent anywhere. Each browser, and each address the app is opened from, keeps its own saved customers, so use **Saved customers → Export all / Import backup** to move them.

The blank form inside the app (NBZ-FNOMI-V07-082025) belongs to Great Eastern Life Assurance (Malaysia) Berhad. This is an independent tool for agents' own use. It is not made, checked or endorsed by Great Eastern. Always check the printed form before the customer signs.

All names and IC numbers in the test and sample files are made up.
